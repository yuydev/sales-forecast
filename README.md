# Sales Forecast

## Excel批量预测

程序会读取Excel，按事业部和SKU分组，搜索最优模型及Alpha/Beta/Gamma参数，并导出预测汇总和逐月明细。

### 历史长度划分规则

程序会先在每个事业部和SKU内部按月份聚合，并将首尾月份之间缺失的月份补为0，然后按补齐后的月份数划分训练集和验证集：

| 补齐后月份数 | 处理方式 |
|---:|---|
| 0-2个月 | 跳过计算，汇总状态为`Skipped` |
| 3-5个月 | 前面的月份训练，最后2个月验证 |
| 6-35个月 | 按约3:1划分，验证集至少2个月 |
| 36个月及以上 | 取最近36个月，30个月训练、6个月验证 |

例如：6个月为4个月训练+2个月验证，10个月为7个月训练+3个月验证，20个月为15个月训练+5个月验证。

短历史序列不启用Holt-Winters季节模型；季节模型只有在训练集至少包含两个完整季节周期，并且验证误差至少改善5%时才会采用。

### 输入Excel格式

默认读取第一个工作表，第一行必须是表头。支持以下中英文列名：

| 业务字段 | 支持的列名 |
|---|---|
| 事业部 | `BusinessUnit`、`Business Unit`、`事业部`、`事业部编码` |
| SKU | `Sku`、`SKU`、`物料编码`、`商品编码` |
| 月份 | `Month`、`月份`、`日期`、`年月` |
| 销量 | `Quantity`、`Qty`、`销量`、`销售数量`、`实际值`、`数量` |

### 运行方式

```bash
dotnet run --project src/SalesForecast -- input.xlsx output.xlsx
```

完整参数顺序：

```bash
dotnet run --project src/SalesForecast -- <输入Excel> <输出Excel> [并发数] [训练月数] [预测月数] [季节周期]
```

例如：

```bash
dotnet run --project src/SalesForecast -- sales.xlsx forecast-result.xlsx 6 30 6 12
```

按`Ctrl+C`可以取消正在运行的预测。输出Excel包含`预测汇总`、`预测明细`和`说明`三个工作表。

## 算法优化说明（v2）

### 新增模型

| 模型 | 说明 |
|---|---|
| `LastValue` | 未来所有月份 = 最近一个月实际销量 |
| `MovingAverage3` | 未来所有月份 = 最近3个月平均销量 |
| `Holt`（阻尼趋势） | 新增 Phi 参数（0.80/0.90/0.95/0.98/1.00），抑制趋势爆炸 |

### 参数搜索范围

| 参数 | 范围 | 说明 |
|---|---|---|
| Alpha | 0.05 ~ 0.80（步长0.05） | 适用所有模型 |
| Beta（Holt） | 0.05 ~ 0.80 | 趋势平滑 |
| Beta（季节模型） | 0.05 ~ 0.50 | 防止趋势过于激进 |
| Gamma（季节模型） | 0.05 ~ 0.50 | **禁止Gamma=0.95出现** |
| Phi（阻尼系数） | 0.80/0.90/0.95/0.98/1.00 | 1.00=无阻尼 |

### 综合评分权重

```
综合评分 = 0.45×sMAPE + 0.30×WAPE + 0.15×归一化MAE + 0.10×稳定性惩罚
```

其中 sMAPE 还混合了最差窗口：`sMAPE = 0.8×平均sMAPE + 0.2×最差窗口sMAPE`。

### 稳定性惩罚

对每个滚动验证窗口的预测计算惩罚，包括：
- 预测最大值超过历史正数最大值1.5倍
- 预测最大值超过历史正数中位数4倍
- 相邻预测环比增长超过3倍
- 预测值非有限或负值

### 基准模型比较

复杂模型（Simple/Holt/HoltWinters）必须比最佳基准模型（LastValue/MovingAverage3）综合评分改善至少5%，否则选择基准模型。

### 预测裁剪

最终预测自动裁剪到安全范围：

```
上界 = min(历史正数最大值 × 1.5, 历史正数中位数 × 4)
下界 = 0
```

诊断字段（导出到汇总工作表）：原始预测最大值、裁剪后最大值、是否裁剪、裁剪点数、裁剪上界、稳定性惩罚、Phi。

### 乘法季节因子保护

`HoltWintersMultiplicative` 的季节因子被限制在 **0.65 ~ 1.50**，防止单个异常月份将因子炸到4.0或更高。

### 重新生成参数

删除已有输出Excel后重新运行程序，或使用不同的 `--trainLength` 参数触发重新搜索：

```bash
dotnet run --project src/SalesForecast -- input.xlsx output.xlsx
```
